# U＝更新狀態／備註（假資料「客戶 A」）

誰：已登入窗口。明細 → 改狀態與備註 → 按「儲存」。  
API：`PATCH /api/admin/enquiries/:id`（body 可帶同筆 `id`；只改 `status`、`note`）。  
沒登入 → 401。不要寫密碼進 git；不要按示範站送出鈕。

| 檢查 | 預期 |
|------|------|
| 狀態 | 可從「新進」改成「處理中」或「已回覆」 |
| 備註 | 可改；儲存後明細與清單一致 |
| 客戶原文 | 訊息等欄位仍只讀、不被改掉 |
| 編號 | 路徑 id 與表單 id 必須同一筆，否則不儲存 |
